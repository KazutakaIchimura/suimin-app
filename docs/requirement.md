# 要件定義書

## プロダクトの目的
スマートリング（SOXAI RING など）が計測した睡眠データを取り込んで振り返れるようにし、睡眠サイクルに合わせて「すっきり起きられる時刻」に起こすことで、睡眠に悩む人の寝起きと生活リズムを改善する。

## 対象ユーザー
- 睡眠に悩む一般の人（寝起きが悪い、睡眠時間が足りているか分からない、生活リズムを整えたい社会人・学生など）
- スマートリングなどのウェアラブル端末を持ち、Apple ヘルスケア／ヘルスコネクトに睡眠データが記録されている人を主に想定する
- 最初の利用者は開発者本人（SOXAI RING 着用）

## 主要な機能

### 1. 睡眠記録（ヘルスケア連携）
- iOS は Apple ヘルスケア、Android はヘルスコネクトから睡眠データ（就寝・起床時刻、睡眠ステージ）を読み込む
  - SOXAI RING のデータは、SOXAI アプリ → ヘルスケア／ヘルスコネクト経由で取り込む（リングと直接は通信しない）
- 1日ごとの睡眠時間・就寝／起床時刻・睡眠ステージの内訳を表示する
- 週・月単位で睡眠時間と就寝／起床時刻の推移をグラフで表示する
- ヘルスケアへの読み取り許可がない場合は、許可の手順を案内する

### 2. スマートアラーム（睡眠サイクル計算型）
- 起床したい時刻を設定すると、睡眠サイクルの区切り（眠りが浅い時刻）の候補を提案し、その時刻にアラームを鳴らす
- 「今から寝る」場合に、起きやすい起床時刻の候補を提案する
- 起床したい時刻を設定したときは、区切りの候補に加えて、起床したい時刻そのものも候補に入れる（区切りがないほど短い睡眠でも鳴らせるようにする）
- 鳴ったアラームは「停止」と「スヌーズ」（少し後にもう一度鳴る）で止められる
- 寝つくまでの時間と睡眠サイクルの長さは、最初は標準値（入眠14分・1サイクル90分）を使い、ヘルスケアの過去データが溜まったら本人の実績から推定した値に切り替える
- 制約：ヘルスケアのデータは起床後の同期で届くため、睡眠中のリアルタイムの眠りの深さに応じて鳴らす機能は対象外とする

### 対象外（今回は作らない）
- リングとの直接通信（Bluetooth）
- 端末のセンサー（加速度・マイク）による睡眠計測
- アカウント登録・クラウド同期
- 入眠サポート（ヒーリング音など）

## ビジネス上のゴール
- AI 駆動開発フロー（設計書 → AI レビュー → TDD → AI レビュー → PR）を一通り実践する学習用・ポートフォリオ用のアプリとする
- 収益化・ストア公開は当面目指さない（開発者本人の実機で使えることをゴールとする）

## 非機能要件
- データは端末内にのみ保存し、外部サーバーへ送信しない（睡眠データは健康情報のため）
- ヘルスケアからは読み取りのみ行い、書き込みはしない
- 対応 OS：iOS・Android の両方（iOS はスマートアラームに OS のアラームの仕組み（AlarmKit）を使うため、iOS 26 以上）
