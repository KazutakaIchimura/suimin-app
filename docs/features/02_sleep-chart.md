# 週・月の推移のグラフ

## 1. 概要
- 睡眠記録（01）で端末内の DB に貯めた睡眠から、**暦の週（月曜〜日曜）・暦の月**ごとに、日ごとの睡眠時間と、主睡眠の就寝〜起床の時刻をグラフで表示する
- 期間の平均（睡眠時間・就寝・起床）を数字でも出す（要件にはないが、振り返りのために人間が 2026-11-26 に「出す」と判断）
- 一覧画面の上に入口を置き、別の画面（`/chart`）で週と月を切り替え、前後の期間へ移る。日をタップするとその日の詳細（01 の詳細画面）へ移る
- グラフの画面でも下に引いて同期でき、同期が終わったら新しいデータで描き直す

## 2. 背景
- 要件「主要な機能 1. 睡眠記録」の「週・月単位で睡眠時間と就寝／起床時刻の推移をグラフで表示する」に対応する。01 ではスコープ外とし、02 で別に設計するとした（`docs/features/01_sleep-record.md` の 8）
- 1日ごとの表示（01）だけでは、睡眠時間が足りているか、就寝・起床の時刻がそろっているか（生活リズム）が分かりにくい。週・月の推移と平均で振り返れるようにする
- 画面構成は、作ったあとに実機で使って変える可能性がある（PR #1 への人間のコメント）。そのため、判定・集計・整形は純粋関数とフックに置き、画面の部品は表示と操作の受け付けだけにする

## 3. 詳細設計

### 3.1 用語と業務ルール
- データは 01 の DB の睡眠をそのまま使う（新しいテーブル・ヘルスケアの読み取りはない）。日付は 01 と同じく睡眠の**帰属日**（起床した日。`wake_date`）で数える
- 「今日」は端末の現在日（`@/lib/clock` の現在時刻を、受け口層から引数で渡す）

#### 期間
- 週：月曜〜日曜の7日。ある日を含む週は、その日以前で最も近い月曜から7日
- 月：1日〜月末（28〜31日。うるう年の2月は29日）
- 切り替えられる範囲
  - 前へ：DB にある睡眠のうち、帰属日が今日以前のもので最も古い帰属日を含む週・月まで
  - 後ろへ：今日を含む週・月まで
  - 帰属日が今日以前の睡眠が1件もなければ（DB が空、または今日より後の帰属日の睡眠だけ）、今日を含む週・月だけ（前へも後ろへも移れない）
- 最初に開くのは、今日を含む週
- 表示する期間は、描画のたびに切り替えられる範囲に収め直す（同期で古い睡眠が消えた・日付が変わって「今日」が進んだなどで、表示中の期間が範囲の外になったら、範囲の端の週・月を出す）。「今日」は描画のたびに `@/lib/clock` から取る
- 週→月→週と切り替えると、元の週に戻らないことがある（最初の日を基準にするため。例：週 11月23日〜29日 → 月 2026年11月 → 週 10月26日〜11月1日）。今の仕様としてこれでよい（2026-11-26 のレビューで確認）
- 週と月を切り替えると、表示していた期間の**最初の日**を含む月・週を出す（例：週 11月23日〜29日 → 月 2026年11月。月 2026年11月 → 11月1日（日）を含む週 10月26日〜11月1日）
- 切り替えた先が切り替えられる範囲の外になるときは、範囲の端の週・月に寄せる（例：最も古い睡眠が 2026-11-20 のとき、月 2026年11月 → 週は 10月26日〜11月1日ではなく 11月16日〜22日。最も古い睡眠が 2026-11-01（日）のとき、週 10月26日〜11月1日 → 月は 2026年10月ではなく 2026年11月）。範囲の外の期間を出すことはない
- 今日より後の帰属日の睡眠（端末の時計を戻した場合など）は、後ろの端が今日を含む週・月なので表示しない

#### 日ごとの値
- 睡眠時間：その日の合計睡眠時間（主睡眠と昼寝の合計。01 の一覧の「合計」と同じ値。01 の `buildDaySummaries` の `totalAsleepMinutes`）
- 就寝・起床：その日の主睡眠の就寝・起床（01 の主睡眠の決め方と同じ。`mainStartAt`・`mainEndAt`）
- 睡眠のない日は値なし（0 として扱わない）。期間の中の未来の日も値なし。DB の睡眠は睡眠時間が1分以上（01 の `asleep_minutes > 0`）なので、睡眠のある日の合計は必ず1分以上
- 棒の高さ：睡眠時間を 0〜720分（12時間）で切った値。720分ちょうどは 720、それを超える日は 720（集計のサービスが切る。描画の部品は切らない）。読み上げ・平均は切る前の値

#### 時刻の縦軸（就寝〜起床の帯）
- 縦軸は、帰属日 D の前日の 18:00 から D の 18:00 まで（24時間）で固定する。0時をまたぐ就寝がつながって見え、週・月を切り替えても比べやすい
- 時刻は「D の前日の 18:00 からの分」（以下「軸の分」。範囲は 0〜1440）に直す。例：前日 23:14 → 314、当日 6:46 → 766
- 夏時間のある地域では軸が23・25時間になる日があるが、扱わない（開発者本人は日本時間。スコープ外）
- 帯は軸の分で就寝から起床まで描く。範囲の外（0 未満・1440 より大きい。夜勤で 16:00 就寝など）にはみ出す部分は、端で切って描く。平均と読み上げは、切る前の実際の時刻を使う
- 就寝・起床がどちらも範囲の外の同じ側（どちらも 0 以下、またはどちらも 1440 以上。例：当日 19:00〜23:00）で、切ると長さが0になる日は、帯を描かない（日ごとのボタンと読み上げは、実際の時刻で出す）。就寝がちょうど 0・起床がちょうど 1440 の日は、軸いっぱいの帯になる

#### 平均
- 期間の中で睡眠のある日だけで計算する（睡眠のない日・未来の日は入れない。未来の日に睡眠があっても入れない）。範囲の外の時刻（夜勤など）もそのまま平均に入れるので、平均が外れた時刻になることがあるが、それでよい（人間が「数字は実際の時刻」と判断）。睡眠のある日が0日なら平均は出さない
- 四捨五入は JavaScript の `Math.round` と同じ（.5 は大きいほうへ。例：12.5 → 13、-0.5 → 0、-1.5 → -1）
- 平均睡眠時間：日ごとの睡眠時間（分）の平均を、分に四捨五入する
- 平均就寝・平均起床：日ごとの就寝・起床を軸の分（切る前の値。0 未満・1440 より大きくてもよい）にした平均を、分に四捨五入して時刻に戻す（例：314 と 346 の平均 330 → 23:30）。0時の前後の就寝を、そのまま平均すると昼の時刻になってしまうのを防ぐため

#### 表示（文言は 01 の 3.4 の形に合わせる）
- 期間の見出し：週は「11月23日（月）〜11月29日（日）」、月は「2026年11月」。週の両端の日付は、それぞれ今年（端末の現在日の年）でなければ年を付ける（01 の `formatDate` と同じ規則。例：今日が 2026年なら「2025年12月29日（月）〜1月4日（日）」、今日が 2027年なら「2025年12月29日（月）〜2026年1月4日（日）」、今日が 2026年で翌年にまたがる週は「12月28日（月）〜2027年1月3日（日）」）
- 平均：「平均 7時間32分」「就寝 23:30」「起床 6:45」（時間は 01 の `formatMinutes`、時刻は「H:MM」で時は0埋めなし）
- 期間に睡眠が1件もなければ「この期間の睡眠データはありません」を出し、平均とグラフは出さない
- 前後への移動：週は「前の週」「次の週」、月は「前の月」「次の月」のボタン。範囲の端では押せない（`disabled`）
- 週・月の切り替え：「週」「月」のボタン。表示中のほうは選択中（`accessibilityState.selected`）
- グラフは上下に2つ：日ごとの睡眠時間の棒（縦軸 0〜12時間。12時間を超える日は 12時間で切る）と、日ごとの就寝〜起床の帯（縦軸 18:00〜翌18:00）。軸の目盛りの文字（「0」「4」「8」「12時間」、「18:00」「0:00」「6:00」「12:00」「18:00」）と日付の文字（週は「25（水）」のように日と曜日、月は「25」のように日だけ）は、グラフの外側に React Native の `Text` で置く（victory-native の軸の文字は Skia のフォントの読み込みが要るため使わない）

#### 日ごとのボタン（重ねたボタン）
- 2つのグラフの上に、日ごとの透明なボタン（`Pressable`）を、日の列に合わせて重ねる。ボタンは React Native の部品なので、タップと読み上げを Jest で確かめられる（グラフの絵そのものは Jest で確かめない）
- 読み上げの説明（`accessibilityLabel`）
  - 日付は 01 の `formatDate`（今年以外は年を付ける）
  - 睡眠のある日：「11月25日（水） 睡眠 7時間42分 就寝 23:14 起床 6:46」
  - 睡眠のない日・未来の日：「11月26日（木） 睡眠データなし」
- 睡眠のある日のボタンを押すと、その日の詳細（`/sleep/<帰属日>`）へ移る。睡眠のない日・未来の日のボタンは押せない（`disabled`）

#### 読み取りと更新
- 一覧と同じく、DB の読み取りは同期関数なので、フックは描画の中で読む（01 の 3.1「読み込み中の表示」）。読み直すのは、データの版番号（01 の store の `dataVersion`）か、読み取りの再試行の回数が変わったときだけ
- 読み取りは 01 の読み取りの窓口 `loadDaySummaries` を使う（全期間の日ごとの要約を読み、期間で絞るのは純粋関数で行う）。失敗のログは窓口が `sleepRecord.loadList` で出す
- 読み取りに失敗したら「睡眠データを読み込めませんでした」と「再試行」ボタン（読み取りをやり直す）だけを出す。この間は下に引けない（再試行で読み直す）
- 一覧画面の「週・月の推移」ボタンは、一覧を表示しているとき（「読み込み中」でなく、DB の読み取りに成功したとき。睡眠が0件で「睡眠データがありません」を出しているときも含む）だけ出す。「読み込み中」の間は 01 の 3.1 どおり「読み込み中」の表示だけ、読み取りに失敗したときは 01 どおり「睡眠データを読み込めませんでした」と「再試行」
- 下に引くと 01 の store の `sync()` を呼び、終わったら（成功・失敗とも）引っ張り中の表示を止める。連携状態が `ready` 以外なら 01 のとおり連携状態の取得だけをして同期しない。同期が成功して版番号が上がれば読み直す。連携状態の案内・同期の失敗表示は一覧画面だけに出し、グラフの画面には出さない
- 「読み込み中」の表示は持たない（DB を描画の中で読むため。連携状態は使わない）

### 中間（`tests/integration/`）
- I6 グラフの画面（`renderRouter` で実際の `src/app/` を読み込む。DB は本物）
  - I6-1 一覧の「週・月の推移」を押すと `/chart` へ移り、今日を含む週の見出しと平均が、DB のデータから期待される文字列で出る
  - I6-2 日ごとのボタンが期間の日数だけ並び、読み上げの説明が DB のデータどおり。睡眠のない日・未来の日は押せない
  - I6-3 睡眠のある日のボタンを押すと、詳細（`/sleep/<帰属日>`）へ移り、その日の詳細が出る
  - I6-4 「月」を押すと月の見出し・平均・日ごとのボタン（その月の日数）に替わり、「週」を押すと週に戻る（3.1 の切り替えの規則どおりの期間）
  - I6-5 前へ・後ろへ移ると見出し・平均・ボタンが替わる。最も古い睡眠の週・月で「前の週／前の月」、今日の週・月で「次の週／次の月」が押せない。睡眠0件なら両方押せない
  - I6-6 期間に睡眠がなければ「この期間の睡眠データはありません」が出て、平均は出ない
  - I6-7 下に引くと同期が走り（ネイティブの読み取り関数が呼ばれる）、引っ張り中の表示が止まる。同期で睡眠が変わると、表示が新しい内容になる。同期が失敗したときも引っ張り中の表示が止まり、エラーは出ず、表示はそのまま。同期で表示中の期間より新しい日だけになり（古い睡眠が消え）表示中の期間が範囲の外になったら、範囲の端の期間が出る。連携状態が `ready` 以外なら、読み取り関数は呼ばれず、引っ張り中の表示が止まる
  - I6-8 グラフの画面を開いたあとに DB を閉じて読み直させる（版番号を上げる）と、「睡眠データを読み込めませんでした」と「再試行」が出て、`sleepRecord.loadList` の error ログが出る。DB を開き直して「再試行」を押すと、期間の見出しと平均が DB のデータどおりの文字列で出る
  - I6-9 グラフの画面に、連携状態の案内・同期の失敗表示が出ない（連携状態が `ready` 以外・同期が失敗したときも）
  - I6-10 一覧画面の「週・月の推移」ボタンは、一覧を表示しているときだけ出る（睡眠0件で「睡眠データがありません」のときも出る。「読み込み中」の間・一覧の読み取りに失敗したときは出ない）
